# Ticket intake

1. Pull the ticket, its parent epic and any linked docs.
2. Write acceptance criteria as testable statements ("Given/When/Then" is fine).
3. List assumptions you're making. Each one is either confirmed or becomes a question.
4. If the ticket mixes two changes, say so and suggest the split.
