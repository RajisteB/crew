# Tech proposal format

1. Problem — what's broken or missing, with evidence.
2. Goals and non-goals.
3. Options considered — at least two, with trade-offs.
4. Proposal — the chosen option in enough detail to estimate.
5. Rollout and rollback.
6. Open questions — each with an owner.
