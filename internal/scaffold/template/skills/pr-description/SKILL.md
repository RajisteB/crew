# PR description

- **What**: one or two sentences.
- **Why**: link the ticket; one sentence of context.
- **How tested**: commands run and what they showed.
- **Risk / rollout**: what could break, how to roll back.

Keep it under 200 words. Reviewers merge short, clear PRs faster.
